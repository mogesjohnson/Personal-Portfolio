# PR #18 assets

Screenshots for the TRACE Workbench project page and its homepage wiring. Production build (`next build` + `next start`), headless Chrome, reduced motion unless the name says `motion`. Desktop shots were taken at 1440 px wide (downscaled to 1200 px here); mobile shots at 390 px wide, 2x.

- `before/` and `after/`: the homepage wiring.
  - `before/` is `grok/add-replay-studio-switchyard` at `7d87e2c` (PR #17 head). The Work section has five projects, the mobile menu has no TRACE entry, and Switchyard's "Next project" goes to Shadow Army.
  - `after/` has the sixth Work project with its `trace` formation (SVG and live particles), the menu entry, and Switchyard → TRACE Workbench in the footer cycle.
- `trace-page-before/`: `/trace-workbench` at `5bf77de`. It framed screenshots of the PR #4 landing page and two 1x Calculator frames.
- `trace-page-after/`: `/trace-workbench` after the review. It is the PR #4 landing page rebuilt in the shared project-detail layout as live text: hero, 01 What it does (four cards), 02 Evidence (the recorded Calculator trace, Fig. 01), 03 How it works (the setup run, Fig. 02) and 04 Scope. There are no screenshots. `menu-mobile-390.jpg` shows the page's menu with the short "TRACE" label on one line. `switchyard-reference-*` shows `/switchyard` captured the same way for comparison. At 390 px the bar label is now hidden on every project page.
- `after/menu-mobile-390.jpg` is the homepage menu with the same short label.
